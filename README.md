# Public Userscripts

A collection of publicly usable userscripts maintained by [danielk-am](https://github.com/danielk-am).

## Scripts

### Facebook → Ads Manager | Focus Mode

Skips the Facebook feed and redirects to Ads Manager. Login, account recovery, checkpoint, and two-step verification pages are left alone; Ads Manager itself is not redirected.

**Install:** Install a userscript manager such as Tampermonkey or Violentmonkey, then [install the script](https://raw.githubusercontent.com/danielk-am/userscripts-public/main/scripts/facebook-ads-manager-focus-mode.user.js).

**Note:** This script redirects Facebook pages to Ads Manager. Review the script and confirm that behavior suits your needs before installing it.

## Updating

The script's `@updateURL` and `@downloadURL` point to its raw GitHub file, so a userscript manager can check for updates there.
